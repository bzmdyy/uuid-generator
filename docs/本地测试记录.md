## 重跑方法

日常自动检查：

```powershell
node --test
```

可选的浏览器检查：先在一个 PowerShell 窗口运行 `node scripts/serve.mjs`；在第二个窗口进入项目目录运行：

```powershell
node scripts/browser-check.mjs
```

浏览器脚本默认使用 `C:/Program Files/Google/Chrome/Application/chrome.exe`。没有这个路径时，可以先设置 `$env:BROWSER_PATH` 为本机 Chrome 或 Edge 的完整程序路径。测试会使用独立的浏览器测试目录，**会将测试 UUID 写入系统剪贴板**，请先保存自己需要保留的剪贴板内容。
