# UUID Generator 项目需求文档

版本：1.0 · 需求确认日期：2026-10-15

## 1. 项目目的与确认范围

这是一个出海网站入门练习，网站名称为 **UUID Generator**。让访客快速生成随机 UUID v4，并让站长走完从本地运行到上线、绑定域名及提交 Google 的完整流程。

本文件依据你已确认的回答编写，作为第一版实施范围。英文为主，支持简体中文；简洁现代，适配手机和电脑；每次生成 1～100 个，默认 1 个；可复制单个或全部。代码先在本地测试。账号已准备好，域名在 Vercel 部署成功后再购买。购买域名及任何付费操作由你决定并执行。

## 2. 完成条件

按顺序完成：功能可用 → 部署 Vercel → 绑定域名 → 可以通过域名直接访问 → 验证 Google Search Console → 提交站点地图。

“站点地图”是给 Google 的网页地址清单。项目会自动生成它，文件名是 `sitemap.xml`。

提交动作完成并在 Search Console 看到提交记录，且没有已知的地址或访问错误，即达到本次提交目标。处理可能稍有延迟；后续观察是否读取成功。**Google 是否收录、何时收录、有无排名，不作为项目完成条件。**

当前交付只包括两份文档、网站代码和本地验证；不能将本地测试通过等同于上述上线全流程已完成。

## 3. 页面与语言

| 项目 | 要求 |
| --- | --- |
| 英文页面 | `/`，默认入口；页面标题包含 UUID Generator |
| 中文页面 | `/zh/`，简体中文 |
| 语言切换 | 页头提供 EN / 简体中文；不根据地区强制跳转 |
| 页面内容 | 名称、简短说明、数量输入框、生成按钮、结果列表、单个复制、全部复制、UUID 说明、常见问题 |
| 样式 | 浅色背景、绿色强调色、清晰排版，无需图片或外部字体 |
| 适配 | 电脑、手机宽度；窄屏可阅读 UUID，长列表可滚动 |
| 页面不存在 | 显示友好提示和返回首页链接 |

第一版只有一个工具页面，分别提供两种语言；不是再增加两个产品功能。切换语言、刷新页面时会生成新的 UUID，不保留上一页结果。

## 4. 功能规则

| 操作 | 预期结果 |
| --- | --- |
| 首次打开或刷新 | 自动生成 1 个 UUID v4 |
| 输入 1～100 的整数后生成 | 显示指定数量，替换旧列表，不追加 |
| 输入空值、0、负数、小数或超过 100 | 显示当前语言的错误提示，保留原有结果 |
| 复制单个 | 只复制对应 UUID，不带序号和说明 |
| 复制全部 | 复制当前整批 UUID，每行一个，不带序号和说明 |
| 复制成功 | 显示成功提示，按钮短暂显示“已复制”或 Copied |
| 浏览器拒绝复制 | 显示手动复制提示，并选中相应结果区域 |
| 浏览器不支持安全生成 | 显示升级浏览器、使用 HTTPS 的提示，不生成替代假数据 |

UUID 格式为 `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`，共 36 个字符（包含 4 个短横线），使用小写字母；`y` 为 8、9、a、b 之一。随机 UUID 发生重复的概率极低，但不承诺绝对不重复。UUID 是标识符，不作为密码或密钥。

## 5. 数据与使用体验

- UUID 在浏览器本机生成；生成和复制不调用外部服务。
- 不保存 UUID，不使用数据库、浏览器历史存储或用户账号。
- 不添加分析追踪和广告；部署服务本身可能保留访问日志。
- 所有按钮和输入框支持键盘操作，输入框有名称，提示可被读屏工具读取。
- 使用现代 Chrome、Edge、Firefox 或 Safari；线上使用 HTTPS。本地通过 `http://localhost:3000` 测试。
- 页面主要说明文字直接写在网页中；关闭 JavaScript 仍能阅读说明，但生成和复制需要启用 JavaScript。

## 6. 帮助搜索引擎识别页面

- 中英文各自有标题和简介。
- 标明各页面的正式网址（代码中叫 canonical），并关联中英文版本（代码中叫 hreflang）。
- 自动输出 `robots.txt`，允许抓取并注明站点地图地址。
- `sitemap.xml` 只包含英文和中文两个正式页面，不包含随机结果、测试地址或不存在的页面。
- 正式域名确定后，在 Vercel 设置 `SITE_URL` 并重新部署，确保所有正式网址指向同一域名。
- Google Search Console 使用域名验证方式，无需给网站添加追踪代码。

## 7. 技术方案（已替你决定）

采用 **HTML + CSS + JavaScript，配合 Node.js 内置脚本构建**。你可以把它理解为“网页内容 + 外观 + 按钮操作”，Node.js 负责把文件整理成可发布的网站。

不引入 React、Next.js 或数据库：当前功能在浏览器内即可完成。项目不需要安装额外的软件包，降低新手遇到安装和版本问题的机会。用 GitHub 保存代码，用 Vercel 发布网站。

生成使用浏览器自带的 `crypto.randomUUID()`，复制使用 `navigator.clipboard.writeText()`。这两个名称供后续维护时查找，无需背诵。

## 8. 第一版不做

登录、个人中心、历史记录、下载、广告、付费、访问统计、其他 UUID 版本、自定义 UUID 格式、后台管理、文章系统和对外接口。后续想加功能时，另行确认范围。

## 9. 验收清单

- [ ] 英文和中文页面均能打开，语言切换正确。
- [ ] 默认生成 1 个；生成 1 个、10 个和 100 个，数量正确。
- [ ] UUID 长度、版本和格式正确，重复生成会替换旧列表。
- [ ] 空值、0、101、负数和小数都不能生成，提示清楚。
- [ ] 单个复制正确；全部复制为每行一个，可粘贴到记事本检查。
- [ ] 拒绝剪贴板权限时，提示手动复制。
- [ ] 手机和电脑可操作，输入、复制按钮不会被遮住。
- [ ] Vercel 的正式生产网址可在未登录的浏览器里访问。
- [ ] 自有域名通过 HTTPS 打开；www 版本跳转到选定的主地址。
- [ ] 网页中的正式地址、语言地址、robots 和站点地图均使用自有主域名。
- [ ] Search Console 显示所有权已验证。
- [ ] 站点地图已提交，留有提交记录；无已知访问或内容错误。
